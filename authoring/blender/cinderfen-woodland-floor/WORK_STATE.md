# Cinderfen woodland-floor kit

Root assigned this separate package after all four nature assets were accepted
and published. The existing nature package is frozen.

Current stage: PAUSED at a stable source/PBR checkpoint after the user's new
character, equipment and town/siege priority. All six closed source meshes and
editable masters are saved. Root accepted the irregular fracture/partial bark
collar and low plant shapes as source direction. All six PBR source close/overall
proofs completed. No runtime model is approved or published. Exact export, bake,
reimport and GM evidence remain. No package render/export process is running.

Finished source triangle counts: fallen limb 9,670 / 3,040 / 422;
fern/wood-sedge 28,500 / 10,976 / 3,122. All six positional audits have zero
boundary, multi-face or loose edges. Boolean internal membrane removal is
limited to coincident opposite tiny faces, with the closed-skin gate retained.
Four independent source tests pass, including closed shells, LOD scale and
reconstruction of tangent normals from the saved metric foliage height maps.

Each branch carries local grain coordinates through its curved side into the
non-radial heartwood survey. New wood material graphs combine those directional
fibres with continuous object-space pigment, damp underside and sparse lichen.
Fresh foliage fields are retained at 1024 pixels with height/normal/ORM evidence.
Source-only PBR images use `_material_source.png`; these are not GLB evidence.

Stable source PBR images: fallen limb overall, large break, side stub and bark;
fern/wood-sedge overall and fronds. Their exact image/master/material-tool hashes
are recorded in `review/<asset>_material_source.json`. The material-preview
masters pack the image maps. Root has not accepted these material renders yet.
Close bark currently has a soft broad field with fine longitudinal detail and
sparse lichen; judge that contrast and fork continuity on actual exports later.

`tools/bake_floor_wood.py` and `tools/export_floor.py` are saved draft tools and
pass Python syntax compilation only. Neither has run. They propose a unique
2048/1024/512 wood atlas, explicit unchanged-geometry hashing, preserved source
UVs/fields and three retained masters. Atlas tangents, bake sharpness, actual
GLB topology, Khronos validation, texture externalization, measured distance
views and publication contracts are all still unverified. No blueprint,
runtime GLB, QC sidecar or global registry/catalog/map entry was created.

On resumption, adapt `review_floor.py` measured distances for these small assets
(limb 4/12/30 m; fern 2.5/8/20 m) and label source versus runtime lighting
accurately before final evidence. Do not copy the inherited alder distance test.

Bounded assets: `frontier_cinderfen_fallen_alder_limb` and
`frontier_cinderfen_fern_wood_sedge`. Both require three authored LODs, complete
PBR, retained editable source, exact reimport review, and GM placement contracts.
Root owns global publication, maps, catalogs, documentation and composition.

Construction uses authored sections and paths, broken-end surveys and physical
leaf outlines. No primitive mesh construction, generic imported model, copied
published geometry or copied texture pixels are permitted.
