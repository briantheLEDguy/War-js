# Regional world production

This board tracks execution of [the approved plan](world-orvr-implementation-plan.md).
An asset counts as delivered only after source, export, material, animation where
applicable, and runtime checks. The user grants standing asset approval; technical evidence remains explicit. A finished asset package does not finish a zone.
